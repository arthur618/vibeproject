# 🎮 Arcade9 · 九宫奇趣屋

> 九个维度，九款纯原生原创微游戏 · 零依赖 HTML5 Canvas + Web Audio 合成音效

一个面向桌面端与移动端的九宫格创意街机网页应用：打开即见 3×3 动态微缩预览大厅，点击任意格子即刻进入一款独立玩法的小游戏，并自动记录每格最高分与 `★` 勋章进度。

## ✨ 项目特性

- **动态 3×3 游乐大厅**：每格独立主题霓虹配色 + 实时动画预览 Canvas，支持 `🎲 随机一局`、`ESC` 返回大厅、`R` 快速重来。
- **零外部依赖**：纯原生 HTML / CSS / ES Modules / HTML5 Canvas，无需打包或安装依赖即可直接运行。
- **纯代码 Web Audio 合成音效**：悬停、切片、虫洞跃迁、激光、爆炸、五声音阶与电音合成器底鼓全部实时生成，支持一键静音。
- **本地进度持久化**：自动在 `localStorage` 保存各游戏最高分与 `★` 勋章解锁状态。

## 🚀 本地运行

项目为纯静态网页，任意本地 HTTP 服务均可启动（因使用 ES Modules，建议通过本地服务器打开而非直接双击 `file://`）：

```bash
python3 -m http.server 8765
```

然后在浏览器访问：`http://localhost:8765`
