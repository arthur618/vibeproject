# vibeproject

纯机器做工，无古法手工 —— 创意 Vibe Coding 项目合集仓库。

## 📦 项目列表

| 目录 | 项目名称 | 简介 |
| :--- | :--- | :--- |
| [`arcade9/`](./arcade9/) | **Arcade9 · 九宫奇趣屋** | 纯原生 HTML5 Canvas + Web Audio 合成音效的九宫格创意小游戏合集（含 9 款原创微游戏） |
| [`moyu/`](./moyu/) | **moyu · 摸鱼游乐场** | 18 个零依赖小游戏：9 个轻量游戏 + 9 个无倒计时益智游戏，支持本地纪录和移动端按钮 |

## 🚀 运行示例

进入对应项目目录启动本地静态服务器即可，例如运行 `arcade9`：

```bash
cd arcade9
python3 -m http.server 8765
```

然后在浏览器打开 `http://localhost:8765`。
