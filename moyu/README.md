# moyu · 摸鱼游乐场

18 个小游戏组成的纯静态网页：9 个轻量游戏，9 个无倒计时的益智游戏。无需安装依赖、无需构建，电脑和手机均可使用。

## 打开方式

下载后直接用浏览器打开 `index.html`。也可以在仓库根目录启动静态服务：

```bash
python3 -m http.server 8765
```

然后访问 `http://localhost:8765/moyu/`。

## 功能与操作

- 点击卡片进入游戏；`Esc` 或关闭按钮返回大厅，结束后可重开。
- 随机开玩、音效开关、每日积分、每个游戏的最佳纪录。
- 方向键操作的游戏也提供屏幕按钮；推箱子和数字合并支持撤销。
- 随机生成可解迷宫、关灯谜题和数字华容道。
- 益智游戏切到后台保留本局状态；计时游戏离开前台后需重新挑战。
- 积分、纪录和音效偏好保存在当前浏览器的 `localStorage`；没有服务端和账号同步。本局棋盘状态不会跨刷新保存。

## 文件与验证

`index.html` 包含全部 HTML、CSS 和 JavaScript，无外部字体、图片或脚本依赖，可离线使用。

已通过 JavaScript 语法检查及模拟 DOM 的游戏逻辑回归测试，包括 18 个入口、通关和结算、计时器清理、随机谜题可解性、撤销与合并规则。该测试不替代真实浏览器的视觉与触控验收。
